# 小秦水果超市 Sylus Fruit Shop Receipt

## 项目介绍

本新人 vibe-coding 了一个秦彻（恋与深空）的小秦水果超市购物清单。  
在这里可以添加想买的多个物品（支持中英双语）、数量和单价，自动生成一个总价，并且打印成收据的形式。

I've created a Vibe-Coding project for a Sylus (from Love and Deepspace) fruit shop shopping list.  
Here, you can add multiple items you wish to buy, with support for both Chinese and English, along with amount and unit prices. It automatically calculates the total and prints it out as a receipt.
